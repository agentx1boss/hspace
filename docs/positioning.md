# HSpace 产品定位说明(权威版)

> 单一事实来源:所有对外文案(落地页 / Marketplace / 社媒 / README)从本页取用。
> 定稿 2026-07-04,基于定位评审六项决议(见 [decisions-log.md](decisions-log.md))。改这页 = 改定位,需走评审。
> **修订稿 2026-07-26(待评审)**:定位重心转向**私密 Markdown 分享 + 阅读体验**,HTML 降为副位能力;同时把**开源**从加分项提为隐私主张的兑付凭证(见 §4 信任底座;适度强调,不作宣传主线)。核心机制叙事(密码、回执、撤回、链接不变)与全部边界承诺不变;变的是主角(demo → 稿)与对照面(公开托管 → 公开分享链接,且对照面全为闭源 SaaS)。见 decisions-log 同日待评审条。

## 1. 定位声明(内部标准句式)

> **对于**用 Cursor / Claude Code 等 AI 编程工具的开发者,**当他们**要把 AI 写好的方案、报告、教程(以及 demo)发给同事和客户看时,**HSpace 是**一个私密的 Markdown 分享工具,**它能**把 .md 一键变成"链接 + 密码"的精排阅读页(HTML 同样原样能跑)——有访问回执、发错了收得回、链接不变可迭代。**不同于** Notion 分享链接 / HackMD / Gist 等默认公开的闭源分享方式,**我们**为"只给该看的人,认真读完"而设计,发布无需注册、30 秒完成,且全栈开源(MIT)、可自建。

对外压缩版(给媒体/介绍用):**"AI 编程时代的私密 Markdown 分享:稿写完,排好版,只给该看的人。"**

对外主判断(英):**"Publish Markdown privately: a clean reading page behind a password — read receipts, revocable access, links that expire."**
对外主判断(中):**"AI 写的稿,排成私密阅读页:密码链接、可撤回、会过期、有访问回执。"**

> 用词留痕(2026-07-26):英文原作 `instant revoke`、中文原作"看谁打开了",均已按事实边界表下修——"即时"目前只对"踢掉某个访问人"成立,"看谁"需登录 + 每人一链。相关实现收敛后可回调(见 §9)。

**品类词与机制词**:品类占位用「私密 Markdown 分享(private Markdown sharing)」;「定向分享」保留为机制叙事(只给该看的人、每人一链、回执)。两者搭配使用,不互斥。

**时代论据(展开文案可用)**:AI 编程工具的产出重心正从"能跑的 HTML demo"移向"长篇 Markdown 方案 / 报告 / 深度调研"——产出越像稿,阅读体验与"只给该看的人"就越是刚需。

**反定位**(帮团队做功能取舍):我们不是网盘、不是协作编辑工具、不是笔记/知识库应用、不是建站平台、不是公开画廊。

## 3. 电梯稿(三个长度)

**10 秒**:HSpace 把 AI 帮你写好的 Markdown 一键变成带密码的精排阅读页,只发给该看的人——有访问回执,发错了收得回。

**30 秒**:用 Claude Code、Cursor 写完一份方案或报告,想发给客户、同事看?丢 .md 原文件,对方要么打不开、要么看到一坨源码;贴成公开链接,又等于发给了全世界。HSpace 反着来:在编辑器或 AI 对话里一键发布,.md 渲染成排版精良的阅读页——标题、表格、代码块、目录、亮暗主题,多篇成合集自带篇间导航;你拿到"链接 + 密码",一次粘贴发走。被打开了几次你都知道(登录后给每人发各自的密码,还能知道是谁看的);发错了人,把他那把密码作废就行,不用惊动其他人。内容改了链接不变。HTML demo 同样原样能跑。无需注册;全栈开源(MIT),不放心放在别人的服务上,十分钟就能跑在自己的 Cloudflare 账号里,能力一点不少。

**60 秒**:在 30 秒版基础上追加——"背后是跑在 Cloudflare 边缘的开源 Worker(R2+D1+KV),密码在边缘校验、防爆破;阅读页不被搜索引擎收录,外壳自包含、无广告,HSpace 自身不加第三方脚本(代码公开,可自查)。除了编辑器插件,还有 MCP server 让 Claude/Cursor 在对话里直接发布,OpenAPI 让任何 agent 接入。核心能力免费。"

### 信任底座:开源(适度强调,不作宣传主线)

开源是隐私主张的兑付凭证——闭源产品的"不看、不追踪"只能靠信任,我们可以让人自己查、把服务搬走。转向隐私主打后值得比过去讲得重一点,**但它是论据不是卖点**:在定位声明、GitHub About、FAQ、自建相关文案里各提一次就够,不铺满每条文案,不打"抵制闭源"的旗,也不做道德优越;只陈述事实,让读者自己下结论。

### 事实边界(可说 / 不可说)——写任何对外文案前先对一遍

> 2026-07-26 经代码核验建立(Codex 对抗式评审发现四处口径与实现不符,见 decisions-log)。**这张表是硬约束**:表右列写"别说"的,任何渠道都不许说。实现推进后同步放宽,不要凭印象提前松口。

| 可说 | 边界 |
|---|---|
| 全栈开源、MIT | 后端 Worker + VS Code 插件 + MCP server + CLI + Claude Code 插件同仓公开 |
| md 阅读页**不执行任何第三方脚本**(2026-07-28 起:原始 HTML 过白名单净化 + CSP `default-src 'none'` / `script-src nonce`);HSpace 自身不加客户端埋点 | 已可去掉"HSpace 自身"这个限定**但只限脚本**:md 里写的 `<script>`/`onerror`/`javascript:` 一律进不去也跑不了。**外链图片仍会照常加载**(`img-src https:`,刻意决策),所以仍别说"阅读页无任何第三方请求"。**HTML 稿(.html)不在此列**——它的卖点是原样能跑,用户自己写的脚本与 CDN 照旧 |
| 回执 = 服务端计次 + 最后访问时间 | 无浏览器指纹、无第三方像素;**但别说"不设 Cookie"**——密码通过后有 `hs_<slug>` 门禁票据(HttpOnly/Secure/SameSite=Lax/24h),单页作用域、不跨站 |
| 密码门是**默认**(客户端一律自动生成 4 位密码) | 不是协议级强制:裸调 API 省略 `password` 可发公开页(刻意保留)。别说"所有页面都有密码""必须设密码";说"默认带密码、推荐带密码" |
| 踢掉某个访问人 = 即时 | 每人一链的 grant 每次访问都校验 `revoked`,旧 Cookie 立刻失效;**但改共享密码不即时**——共享密码 Cookie 不带密码版本号,已验证的浏览器最长 24 小时内仍可读。别用无限定的"即时撤回 / instant revoke" |
| 自建 = 完整能力 | 无版本分层;插件、MCP 与 CLI 都可指向自建地址(`HSPACE_API_BASE`) |
| 落地页有第一方埋点(无 Cookie/PII) | 阅读页没有;被问到如实说,不必主动铺开 |
| 回执的粒度分档 | 匿名只有总打开次数;**"谁看了"需要登录 + 每人一链**。匿名语境别说"谁看了",说"被打开几次" |

写文案的规则:
- **卖结果不卖手段**(说"收得回",不说"边缘密码网关");私密是手段,可控才是结果。
- **隐私主张要有出口,但不必句句带开源**:承诺"不看、不追踪、不变现"这类不可验证的话时,跟一句"代码公开可自查/可自建"作担保;已经在讲具体机制(密码门、会过期)的地方不用再补。开源提得太密会像在辩解。
- **Markdown 在前,HTML 在后**:凡并列出现一律写「Markdown/HTML」「.md(或 HTML)」;md 是主角,HTML 是"同样原样能跑"的副位能力,不贬低、不领衔。
- **钩子+钩子,不要钩子+说明**:slogan 的每一拍都要勾人;"给谁/怎么做"这类说明交给副位。
- **"派活型的你"禁用**:第二人称只可用于赞美/赋权("你说了算"),不可用于分工指令("你来递")——后者是客服腔。
- **无人称优先**:让产品自己说话(稿出即递),而非对用户喊话。

## 7. 目标人群与场景(判断"该不该做某功能"时对照)

**主画像**:用 AI 编程工具(Cursor / Claude Code / Copilot / v0 / bolt)高频产出 Markdown/HTML 的开发者。画像不变,但其产出重心正从 demo 移向长文档(方案、报告、深度调研)——文案与功能优先服务后者。
**核心场景**:① AI 对话里生成的方案/报告,排好版直接发出去;② 技术方案/文档发同事圈阅;③ demo 发客户 review。
**外扩顺序**:技术型 PM → 咨询/交付型顾问 → 设计师(修订:顾问前移——其交付物即文档,与 md 主打同构)。**外扩触发条件**(呼应商业假设探针):主画像周活发布者 > 200 且 7 日留存 > 25%,才启动下一环人群的测试;此前所有文案与功能只对主画像负责。
**不服务**:要建站的人、要长期挂博客/文档站的人、要协作编辑的人、要公开传播涨粉的人。

## 8. 边界承诺(对外可复述)

- 永不做公开画廊——私密是产品身份,不是可切换的选项
- 永不做广告/数据变现——HSpace 自身不给阅读页加第三方脚本、不加客户端埋点,不被搜索引擎收录(你 md 里自己写的外链资源不在此列)
- **密码门是默认与推荐,不是协议级强制**——所有一等公民客户端(VS Code 插件、MCP、CLI、Claude Code 插件)发布时一律自动生成 4 位密码,不给"发个公开页"留快捷入口;但裸调 API 省略 `password` 仍可发公开页,这是刻意保留的自由度(自建者、agent 集成、公开教程都用得上)。因此对外说"默认带密码",不说"所有页面都有密码"
- **自建 = 完整能力,开源不阉割**——全栈 MIT(后端 Worker + VS Code 插件 + MCP server + CLI + Claude Code 插件同仓公开),永不做"开源版 / 企业版"分层;插件、MCP 与 CLI 永远可指向自建地址。这条同时是上面几条隐私承诺的兑付凭证:代码可查、服务可搬走
- 不做多文件站点托管、不做构建
- **所有链接都有有效期,没有永久链接**——匿名最长 7 天(一次性、不可续)、登录最长 30 天/期,到期前可续期,弃置即自动过期清场。这不是限制而是身份:"稿"是给人读的,不是要长期挂着的站点;读完了就该过期(守"不做托管"红线,也是隐私与滥用的天然泄压阀)。md 优先后这条更要主动讲——文档比 demo 更容易被期待"永久存放",到期叙事必须走在质疑前面。
- **匿名故意保持轻量,鼓励登录**——匿名只保"零注册 30 秒发一稿"的顺滑首体验(单页 ≤512KB / 7 天 / 合集 ≤5 篇);每人一链、版本历史/回滚、续期、更大体积与合集都是登录(免费)才解锁。重度/认真使用自然导向账号,但绝不给头牌"发一稿"加注册门槛。

## 9. 口径与实现的差距(分阶段收敛)

> 2026-07-26 建立。Codex 对抗式评审比对了修订稿与代码,发现若干"文案已经在说、实现还没到位"的地方。处理原则:**文案先下修到事实,实现分阶段补齐,补一项放宽一项**。放宽的动作是改 §4 事实边界表 + 本表,不是凭感觉在某处文案里悄悄说回去。

| # | 承诺 | 现状 | 文案当前口径 | 收敛动作 | 优先级 |
|---|---|---|---|---|---|
| 1 | 改共享密码即时撤回 | 共享密码 Cookie 不带密码版本号,已验证浏览器最长 24h 仍可读(每人一链的踢人**是**即时的,每次访问校验 `revoked`) | 只说"踢掉某个访问人即时生效""改密码挡住后续访问";禁用无限定的 instant revoke | 给 pages 加 password revision,签进 Cookie、每次访问比对,改密码时原子递增;测试旧 Cookie 立即失效 —— 已开 [#18](https://github.com/agentx1boss/hspace/issues/18),暂不实现 | 高(最贴近"收得回"这根支柱) |
